KALA LAYA NEPAL — REGISTRATION PAGE

Files:
- index.html: page structure and form
- style.css: responsive layout and styling
- script.js: client-side validation, password visibility, mobile navigation

How to run:
1. Extract this ZIP.
2. Keep index.html, style.css and script.js in the same folder.
3. Open index.html in a browser, or open the folder in VS Code and use Live Server.

Important:
This is a front-end demo. It validates form fields in the browser but does not create or save user accounts.
To register real users, connect the form to a backend and database. Replace the sample login/search placeholders.
The cultural background currently uses an online Unsplash image URL, so internet access is needed for that image and Google Fonts.
